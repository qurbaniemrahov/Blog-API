# Northstar Blog Console

Laravel 13 əsaslı blog idarəetmə API-si və JavaScript admin paneli.

Əsas quraşdırma və istifadə təlimatları [backend/README.md](backend/README.md) faylındadır.

## Sürətli başlanğıc

```bash
cd backend
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```
